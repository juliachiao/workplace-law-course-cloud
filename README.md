# 職場法律必修課（雲端登入版）

SYSTEX 精誠資訊「職場法律必修課」線上學習平台，畢業專題作品。

## 主要功能

**學員端（index.html）**
- 登入：Google 帳號登入（學習紀錄同步到雲端）、員工編號登入、示範帳號（E001 員工／E002 主管）
- 依身分分配教材：學生、一般員工 → 員工篇 4 單元；老師、主管 → 主管篇 2 單元
- 課程：封面 → 課程介紹 → 影片（YouTube，續播、防跳轉）→ 單元測驗 → 錯題本
- 總測驗：完成所有單元後解鎖，80 分通過
- 3D 闖關遊戲（員工篇／主管篇），內嵌於課程網站
- 重點整理：各單元視覺化重點，可列印或存成 PDF
- 求助資源：情境處理步驟、公司內部窗口、外部專線、法規連結
- 學習滿意度問卷：完成總測驗後填寫（課程滿意度、SUS 系統易用性量表、學習成效自評、開放式回饋）

**管理後台（admin.html，預設帳號 admin／admin123）**
- 儀表板、數據分析（單元成效、分數分布、題目分析、校內外／身分／部門比較）
- 問卷結果（回收率、各題平均與分布、SUS 分數）
- 載入雲端數據、匯出完整 Excel（7 個工作表）、備份與合併

## 檔案結構

| 檔案 | 說明 |
|---|---|
| `index.html` | 學員端網頁 |
| `admin.html` | 管理後台 |
| `js/app.js` | 學員端主程式（課程、測驗、重點整理、求助資源、問卷） |
| `js/data.js` | 資料存取（瀏覽器儲存、問卷題目） |
| `js/cloud.js` | Google 登入與雲端同步（Firebase） |
| `js/admin.js` | 管理後台 |
| `js/firebase-config.js` | Firebase 專案設定 |
| `css/style.css` | 樣式 |
| `firestore.rules` | Firestore 安全規則（貼到 Firebase 控制台） |
| `SETUP.md` | Firebase 設定步驟 |

## 部署注意

網站換到新的網址時，要到 Firebase → Authentication → 設定 → **授權網域** 新增新網址的網域，Google 登入才能使用。
